# Use Case 2 --- Grounding Data Quality Assessment

## Unit mapping

**Review Data for Grounding (Accuracy, Relevance, Timeliness,
Cleanliness, Availability)** \## Scenario The operations agent returns
conflicting service targets. \## Learner task Evaluate all files in
`Training-Data/Grounding-Challenge/`. For each source document:
authority/SME validation, scenario relevance, effective date,
duplicates/noise, access scope, and remediation. \## Deliverable
**Grounding Data Quality Scorecard** and remediation plan. \## Key
lesson A source can contain true information and still be poor grounding
because it is irrelevant, stale, noisy, or unavailable to the intended
user.
