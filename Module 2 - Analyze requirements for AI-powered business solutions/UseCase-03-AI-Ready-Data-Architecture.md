# Use Case 3 --- AI-Ready Enterprise Data Architecture

## Unit mapping

**Organize Business Solution Data to Be Available for Other AI Systems**
\## Scenario Contoso information is distributed across CRM, files,
collaboration content, databases, and operational systems. Multiple AI
solutions need governed access. \## Learner task Design layers for
business systems, ingestion/transformation, curated enterprise data,
governance/access, semantic/retrieval, and AI consumers. For each domain
record owner, authoritative source, schema/metadata, sensitivity,
refresh, access method, and consumers. \## Microsoft architecture
categories highlighted by the module SharePoint/OneDrive, Dataverse,
Azure storage/databases, Fabric/lakehouse patterns, Microsoft Graph
semantic indexing, APIs/connectors, RAG retrieval components, and
Microsoft Purview governance. \## Deliverable **AI-Ready Data
Architecture + Data Source Register**.
